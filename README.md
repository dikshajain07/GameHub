# GameHub

A simple gaming website built using **HTML, CSS, and JavaScript**.

## Games

- Tic Tac Toe
- Stone Paper Scissors

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Choose a game and start playing!

## About

GameHub is a beginner-friendly project created to practice frontend development and JavaScript by building simple interactive games.
